# Hellforge 1.0.0 — Initial Release

Hellforge is a Windows launcher for classic DOOM games and source ports, built with Tauri, Rust, React and TypeScript.

## Features
- IWAD, mod and map libraries
- Custom profiles, load order and cover art
- Source-port executable selection
- OBSIDIAN map generator integration
- Launcher playtime and launch statistics
- Seven visual themes and 23 interface languages
- Profile grouping, search and sorting
- Rename library entries and open library folders in Windows Explorer

## Requirements
- Windows 10/11
- Your own compatible game IWAD files and a supported source port (such as GZDoom)
- OBSIDIAN is installed separately for map generation

Hellforge does not include commercial game assets or third-party source ports.

## Installation
Download the Windows installer attached to this release, run it and add your game files and source port in Hellforge.
