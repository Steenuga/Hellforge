# Hellforge 1.1.1 - Mod Library UI Polish

- Компактні рядки модів з фіксованою іконкою 48 × 48 px.
- Різні іконки для глобальних модифікацій, геймплею, HUD, музики, графіки, патчів та власних категорій.
- Вирівняні назви, шляхи, списки категорій і кнопки дій.
- Повні шляхи та назви доступні в підказці при наведенні.
- Збережено функції групування модів та двопанельного редактора з версії 1.1.

**Увага:** Метадані категорій і прив'язки одноразових модів у цій гілці все ще зберігаються в localStorage, не в SQLite. Перед публічним стабільним релізом потрібні міграція до SQLite та перевірка збірки через GitHub Actions.
