# Hellforge 1.1.3 - Окрема папка одноразових модів

- Одноразові моди імпортуються в кореневу папку даних Hellforge `profile-mods/`, окремо від загальної `mods/`.
- Для кожної збірки створюється окрема вкладена папка з безпечною назвою на основі ID збірки.
- У редакторі збірки додано кнопку відкриття кореневої папки одноразових модів.
- Якщо той самий файл уже є у загальній бібліотеці, програма запропонує додати його звичайним способом, замість дублювання.
- При видаленні мода підтримується видалення з керованої папки `profile-mods/`.
- При видаленні збірки файли одноразових модів автоматично не видаляються, щоб уникнути втрати даних.
- Старі імпортовані одноразові моди залишаються на своїх поточних шляхах; автоматичного переміщення немає.

Для релізу потрібна Windows-збірка через GitHub Actions і перевірка інсталятора.
