# Hellforge 1.1.2 - Mod Library Localization & SQLite

- Перекладено нові основні елементи бібліотеки модів, категорії та редактор збірок для 22 додаткових мов; українська є оригіналом.
- Збережено попередні користувацькі переклади без змін.
- Категорії, прив’язки одноразових модів та стан групування зберігаються у SQLite (таблиця `mod_library_settings`).
- При першому запуску дані з попереднього localStorage використовуються як початкові, якщо у SQLite ще немає запису.
- Перевірка словників автоматизована.

**Обмеження:** повну Windows-компіляцію не виконано у цьому середовищі; збирай через GitHub Actions і перевіряй інсталятор. Резервна копія бібліотеки поки не включає таблицю `mod_library_settings`, тому перед очищенням даних програми окремо збережи її каталог.
